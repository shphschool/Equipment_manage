# 校园设备管理平台

面向学校科创教室 / 设备中心的资产管理与学生借用登记系统。

技术栈：Next.js 16 · TypeScript · Tailwind CSS v4 · Neon / Vercel Postgres。

## 功能

- **设备管理**：固定资产 / 低值物资台账，支持资产编号、规格型号、分类、单价、库存，CSV 批量导入与搜索筛选。
- **学生借用登记**：学生登记固定资产借用。
  - 3D 打印机：填写姓名、班级、联系方式，并上传可导入 Bambu Studio 的模型文件（`.3mf` / `.stl` / `.obj` / `.step` 等）。
  - 其它设备：填写姓名、班级、联系方式和使用时间段。
  - 同一资产时间段防冲突；负责人可审核通过、拒绝、完成或取消。
- **3D 打印服务**：打印工单流转（待接单 → 打印中 → 待交付 → 已交付）。
- **管理员登录**：仅管理员可访问，密码哈希校验 + HttpOnly 会话。
