# 开发与 AI 协作说明

## 需求

1. 读取 `科创教室.xlsx`，将「固定资产」「低值」两个工作表中的资产导入现有数据库。
2. 低值物资中同一品种有多件的，每个物品单独编号；编号格式延续固定资产表中的编号格式。
3. 完善预约系统，预约对象为固定资产：
   - 3D 打印机：学生需提供班级、姓名、联系方式和可导入 Bambu Studio 的文件；
   - 其它设备：学生需提供姓名、班级、联系方式和使用的起止时间。
4. 原「固定资产预约」统一写成「学生借用登记」；原来的「学生借用登记」区域不再需要。
5. 打印负责人联系方式尚未确定，先放一下。
6. 使用 AI 完成时，一并提供相关的 skill 和 markdown 文件。

## AI skill 与 Markdown

- `office-xlsx`：读取和生成 Excel。
- `image-reading` / `vision-analyze`：检查页面截图和表格渲染。
- `load_workspace_dependencies`：提供 Python / openpyxl 运行环境。
- 项目 Markdown：`README.md`、本文件；skill 实现位于 DSH 运行环境，未复制进仓库。
